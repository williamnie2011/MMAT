# 离线口算练习机

一台脱离电脑与网络、开机即用的掌上口算练习机。

随机出题 → 按键作答 → 实时判对错 → 错题统计 → 强制重做直到全部答对。

## 仓库结构

| 目录 | 内容 | 状态 |
|---|---|---|
| `core/` | 逻辑内核（C++），含四则运算、判题、计分、连对统计、错题重做状态机 | ✅ 已验证跑通 |
| `hardware/` | 硬件层（Raspberry Pi Pico / RP2040），接线表与实物照片 | 🟡 焊接进行中，未通电调试 |

## 为什么分成两层

我先把纯逻辑写成可独立运行的 C++ 程序，在电脑上验证逻辑完全正确；
再把它移植到硬件层。这样逻辑 bug 和硬件 bug 不会混在一起，
而且逻辑层可以随时回归测试。

## 运行内核

```bash
cd core
make
./kousuan
```

按提示输入答案（只输入数字，回车提交）。

## 已实现的功能

- **四则运算随机出题** —— 用函数指针数组随机选择运算
- **按运算类型过滤非法算式** —— 详见下方「设计要点」
- **实时判对错、计分**（分数不会为负）
- **连续答对计数**（记录最高连对）
- **错题记录与强制重做** —— 答错的题会反复出现，直到全部答对
- **输入断开保护** —— `cin` 失败时安全退出，不会死循环

## 设计要点

### 每种运算的合法域不同

这是实现四则运算时最容易漏的地方：

| 运算 | 约束 | 原因 |
|---|---|---|
| 加法 | `a + b <= 10` | 控制在个位数加法范围 |
| 减法 | `a - b >= 0` | 不出现负数结果 |
| 乘法 | `a * b <= 100` | 控制乘积范围 |
| 除法 | `b != 0 && a % b == 0` | 必须整除，不出现小数 |

生成时用「重试直到合法」的方式，并加了 `guard` 上限防止死循环。

实测：除法在 `[1,9]×[1,9]` 范围内的合法组合只有 23/81（28.4%），
平均需要重试 3.5 次。如果没有 guard，把取值范围放大时会出现明显卡顿。

## 已知限制

- 硬件层整机尚未通电调试（洞洞板焊接中）
- `srand(time(0))` 在 Pico 无 RTC 时种子固定，移植时需改用 `get_rand_32()`
  或 `time_us_32()`，否则每次开机题目相同
- 手写输入未实现 —— Pico 算力不足以跑视觉模型，计划改用带 BPU 的平台
